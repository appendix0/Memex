# concepts

**Goes here:** A mental model or framework you would teach someone — a defined
idea the rest of the Library leans on. `type: concept`.

**Does NOT go here:** Something someone else wrote (`sources/`). A finished
piece written for readers (`writing/`). A rule about how to work (`notes/`, or a
`## Rules` block).

A concept Book earns its place by being **referenced**. If nothing links to it,
it is a note that flatters itself.
