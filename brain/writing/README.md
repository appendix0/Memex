# writing

**Goes here:** A finished prose artifact, or one being drafted for readers — a
manuscript, an essay, a site, a post. `type: writing`.

**Does NOT go here:** The framework behind it (`concepts/`). The measurements it
reports (`research/`). The code it describes (`projects/`).

The Book is **about** the artifact; it is not the artifact. It holds where the
draft lives, what claim it makes, what is unresolved, and what has been checked.

## Rules

- **Every number in a draft names the run that produced it.** A figure whose
  provenance cannot be recovered does not go in.
- A claim in the draft that contradicts a Book on `research/` is a defect in one
  of them. Flag it; do not quietly change either.
