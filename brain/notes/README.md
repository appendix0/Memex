# notes

**Goes here:** Standing guidance that is not a person, project, campaign,
concept, manuscript, machine or source — `type: note`. What the owner wants held
to over time, and how the agent is meant to behave.

**Does NOT go here:** Anything with a shelf of its own. A note that turns out to
be a concept is retyped and moved; see [[CLASSIFICATION]].

Nearly every Book here is about a person and therefore carries
`visibility: vault`. In the Library this system was built for, six shelves once
held them — `corrections/`, `direction/`, `frameworks/`, `preferences/`,
`routine/`, `service/` — one shelf per aspect of one person, which is how that
person came to sit on eight shelves at once. **The aspect is now the filename
and `about:` is the tie.**
