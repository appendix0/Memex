# How to work with the owner

**This is an example Book.** `memex start` reads this Book by slug and injects
it into every session, so it is the highest-leverage file in the Library:
whatever is written here is applied before the conversation begins.

Standing guidance about a person is a `note` carrying `about:` naming them —
never a second Book on `people/`, and never six shelves named after the six
aspects. The aspect is the filename; the tie is the facet.

## Rules

- **Answer in the language the deliverable needs**, whatever language the
  request arrives in.
- **Points, not essays.** Lead with the answer. Give the command plus the one
  non-obvious caveat.
- **Read the documentation before trial-and-error.** New tool or third-party
  API → fetch the official docs first, before planning or quoting limits.
- **Ask first on ambiguity.** Answering a question that should have been
  resolved is the lesser sin; a wrong action that has to be undone is worse.
- **Leave the environment clean.** Once a code path or decision is retired,
  remove what it left behind in the same pass.
