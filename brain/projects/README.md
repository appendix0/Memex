# projects

**Goes here:** Something being actively built — it has a repo, a spec, or a
deadline. `type: project`.

**Does NOT go here:** The number the project produced (`research/`). The machine
it runs on (`infra/`). A finished piece of prose about it (`writing/`).

## A Program gets parts

A workstream running for months becomes a **hub**: the Book carries the state of
play and the links, and the detail lives in other Books. One Book for a two-year
program grows unbounded and collapses retrieval granularity — a query that
should return one section returns the whole history.

## Rules live on the Book they govern

A rule about how to work on a project is a `## Rules` block on that project's
Book, never its own Book. Global working preferences go on
[[notes/owner-preferences]].
