# research

**Goes here:** Measured results, label sets, calibration figures, campaign
outcomes, claims destined for a report. `type: research`.

**Does NOT go here:** The code that produced the number (`projects/`).
Methodology you would teach (`concepts/`).

## APPEND-ONLY — timeline only, no compiled-truth layer

Books on this shelf have **no layer an agent may rewrite**. Results accumulate
in order, each with the date and the run that produced it.

An agent may **flag** a contradiction between two results. Only the owner
resolves one. **An agent that reconciles two conflicting results has destroyed
evidence** — and the destruction is invisible afterwards, because the surviving
text reads as though it were always the only result.

This is the shelf where supersession must stay visible: a figure that went
11/12 → 39/39 → 67/68 tells you something the last number alone cannot.
